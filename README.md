# Bài tập giao diện trang tin

Trang tin tiếng Việt được dựng theo ảnh mẫu bằng HTML, CSS và JavaScript.

## Chạy demo

Tải hoặc clone repository, sau đó mở `BAI_NOP_TRANG_TIN/index.html` bằng Chrome hoặc Edge. Không cần cài thư viện hoặc chạy máy chủ.

## Các file chính

| File | Vai trò |
| --- | --- |
| `BAI_NOP_TRANG_TIN/index.html` | Nội dung và cấu trúc trang |
| `BAI_NOP_TRANG_TIN/style.css` | Kiểu chữ, màu sắc, bố cục và responsive |
| `BAI_NOP_TRANG_TIN/app.js` | Mở và đóng hộp thoại bài viết |
| `BAI_NOP_TRANG_TIN/assets/reference.png` | Ảnh mẫu dùng để hiển thị ba vùng ảnh |
| `BAI_NOP_TRANG_TIN/HUONG_DAN.html` | Hướng dẫn đọc trong trình duyệt |
| `BAI_NOP_TRANG_TIN/HUONG_DAN.md` | Hướng dẫn đọc mã nguồn và trình bày bài |

Bài là demo tĩnh. Menu chưa lọc tin; thời gian và số bình luận là dữ liệu minh họa. Chi tiết cách dựng ảnh và phạm vi chức năng được mô tả trong hướng dẫn.
